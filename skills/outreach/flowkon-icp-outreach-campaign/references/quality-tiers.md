# Reporting message quality tiers honestly

When writing personalized messages across a batch of leads (Phase 4 of the
main skill), research depth will vary lead-to-lead — some people have a
searchable public footprint (press coverage, company "about" pages, award
listings), most only have a LinkedIn headline to go on. Both are valid inputs
for a good message, but they are not the same *quality* of message, and the
user should know which is which.

## The three tiers (report explicitly, don't blur them)

**Tier 1 — Deep-research backed.** Found via `web_search`: a specific,
verifiable fact (a named client, an award, a founding story, a real quote,
a stat from a company site). The message can open on that fact directly.
Strongest tier — use it whenever search turns up something real.

**Tier 2 — Headline-mined + sharp copywriting.** No useful external search
result, but the LinkedIn headline itself has enough specific texture (a
named specialty, a stated business model, a distinctive phrase) to write a
non-generic message off of. Still personalized, just shallower.

**Tier 3 — Minimal signal.** Sparse headline, no distinguishing detail
available. Write the tightest, most honest message you can, but don't
manufacture specificity that isn't there — a vague-but-honest message beats
a confident-sounding fabrication.

## How to report this to the user

At the end of a batch, group leads by tier and name what's in each, e.g.:

> **Deep-research backed (4):** Name (fact found) ...
> **Headline-mined + sharper copy (5):** Name ...
> **Sharpened, headline-specific copy (11):** Name ...

This lets the user spot-check the leads that matter most to them (often the
Tier 1s, since those took real research) and know which ones to personally
review before a batch send. Never present all messages as uniformly deep
if they aren't — that's the exact complaint ("not very impressive," "do more
research") that triggers this whole phase in the first place, and glossing
over the tiers just reproduces the problem one level up.
